# Gem Guardians 전투 규칙 (잼 = 타워)

이 문서는 전투(타워 디펜스) 로직의 기준이다. 퍼즐 규칙은 docs/plan.md를 따른다. 코드에 없는 동작을 임의로 만들지 말고, 애매하면 이 문서를 먼저 갱신한 뒤 구현한다.

작성 2026-11-03 · 이전 컨셉(잼 = 히어로)을 대체한다. 
v2 (2026-11-03): 탑 특수 기술·상태 이상은 나중에 "업그레이드"로 넣는다. 지금은 **기본 투사체만**.

## 1. 한 줄 요약
성벽 위에 잼 모양 수정탑 5개가 서 있고, 멀리(오른쪽)에서 걸어오는 적에게 투사체를 쏜다. 탑은 같은 색 잼이 퍼즐에서 터질 때만 쏜다 - 자동 공격은 없다.

## 2. 바뀌지 않는 것
- 7x7 퍼즐 보드(화면 아래 2/3), 퍼즐 규칙(docs/plan.md) 전부, Canvas 렌더링, 반응형·포인터 입력 구조.
- 잼 에셋 `art/gem-guardians-assets` 그대로(보드용). 다크 판타지 픽셀 아트, 25색 팔레트.
- 전투 영역은 화면 위 1/3.

## 3. 전투 화면 배치 (기본값)
```
┌──────────────────────────────────────────┐
│ ▲ ◆      ·   ·    👹  👹   👹      ← 등장 │  화면 위 1/3
│■■ ▼ ⬠ ■■  ·  적 진행 길 (오른쪽 → 왼쪽)  │
│ 성벽+탑5   │                              │
└──────────────────────────────────────────┘
│              7x7 퍼즐 보드                │  화면 아래 2/3
```
- 옆에서 보는 시점. 왼쪽 약 30% = 성벽과 탑 5개(뒷줄 3, 앞줄 2로 엇갈려 배치), 나머지 70% = 적이 걷는 길.
- 적은 오른쪽 끝에서 나타나 왼쪽 성벽으로 걸어온다. 성벽에 닿으면 멈춰서 성벽을 공격한다.
- **실패**: 성벽 HP 0 → 재도전. **클리어**: 웨이브의 적을 모두 처치 → 다음 스테이지 자동 이동.
- 기존 1-2-1 전투 틀(왼쪽 파티, 오른쪽 적)과 방향이 같아서 코드 변경이 작다. "파티"가 "성벽 + 탑"으로 바뀌는 것.
- 연출: 퍼즐에서 잼이 터지면 그 잼에서 작은 빛 조각이 같은 색 탑으로 날아가고, 탑이 빛난 뒤 발사한다.

## 4. 탑 규칙 (지금 만들 것)
| 항목 | 기본값 |
|---|---|
| 투사체 | 탑마다 자기 색 투사체 1종. 가장 앞(성벽에 가장 가까운) 적 1마리를 향해 날아가 맞으면 피해. 단, 이미 날아가는 탄의 예상 피해로 죽을 적은 건너뛰고 그 다음 적을 노린다(모두 죽을 예정이면 맨 앞). 범위·관통·상태 이상 없음 |
| 공격 조건 | 자동 공격 없음. 같은 색 잼이 퍼즐에서 터질 때만 쏜다(퍼즐 사격) |
| 퍼즐 사격 | 같은 색 잼 n개 제거 → 그 색 탑이 즉시 1발, 피해 = 공격력 × n × (1 + 0.1 × (연쇄 − 1)) − 적 방어력, 최소 1. 연쇄 = `cascadeCount`. 콤보 스트릭(plan.md §18 `comboStreak`, `COMBO_CONFIG.tiers`)은 아직 연결하지 않음 |
| 특수 잼 | 퍼즐 효과(줄·폭발·상자·컬러)는 그대로. 그 효과로 지워진 잼도 색별로 세어 같은 공식으로 쏜다. 그래서 특수 잼을 쓰면 많이 지워진 만큼 자연히 세진다 |
| 성장 | 탑 레벨(공격력·공속·사거리). 룬 소켓은 추후 |

- 5개 탑의 수치는 처음엔 같게 시작하고, 차이는 투사체 모양·색만 둔다. 수치는 `config/balance.json`의 `tower`에서, 탑 5개의 색·이름·투사체 모양은 그 안의 `tower.towers`에서 조정(docs/balance.md §2).
- 탑 모양은 잼 실루엣 그대로: 빨강 팔각 사각형, 파랑 삼각형, 노랑 역삼각형, 녹색 다이아몬드, 보라 오각형.

## 5. 적 (지금 만들 것)
- 스탯: 이동속도, 체력, 방어도, 성벽 공격력(+확장 고려). 지금은 근접만(성벽에 닿아야 공격).
- 첫 웨이브용: 슬라임(느림, 체력 낮음), 고블린(빠름), 오크(체력 높음). 그린 오크를 바로 쓰고, 슬라임·고블린은 다크 톤으로 다시 그린다.
- 엘프·기사·마법사도 히어로 대신 적으로 쓴다. 원거리 공격·엘리트 능력은 업그레이드 단계와 함께 추후.
- 스프라이트는 규칙대로 오른쪽을 보게 그리고, 적은 왼쪽으로 걸으니 **코드에서 좌우 반전**(`ctx.scale(-1, 1)`).

## 6. 나중에 업그레이드로 넣을 것 (지금은 만들지 않음)
기획만 남겨둔다. 투사체 구조를 만들 때 "타깃 1마리 / 범위 / 관통 / 추적" 같은 종류를 나중에 추가할 수 있게만 해두면 된다.

**색별 업그레이드 후보**
| 색 | 탑 이름(가제) | 업그레이드 후보 |
|---|---|---|
| 빨강 | 화염 수정탑 | 착탄 범위 폭발, 화상 |
| 파랑 | 서리 첨탑 | 관통 2마리, 둔화 |
| 노랑 | 뇌전탑 | 튕기는 번개, 기절 확률 |
| 녹색 | 가시독탑 | 독 중첩, 명중 시 성벽 회복 |
| 보라 | 저주 오벨리스크 | 긴 사거리, 방어력 감소 |

**특수 잼 기술 후보**
| 특수 잼 | 기술 후보 |
|---|---|
| 라인 가로 | 관통 광선: 길 끝까지 가로 빔 |
| 라인 세로 | 낙하 기둥: 맨 앞 적에게 빛기둥 + 넉백 |
| 폭탄 | 용암 포격: 범위 피해 |
| 상자 | 영혼 불꽃 2발: 랜덤 적 2마리 추적 |
| 컬러 | 그 색 탑의 궁극기(운석, 눈보라, 뇌우, 독안개, 파멸의 표식) |
| 조합 | 합동 기술(십자 광선, 대포격, 5탑 일제 사격 등) |

그 밖에 추후: 탑 구매·장착(= 퍼즐 잼 종류), 룬 소켓, 원거리·엘리트·보스 적, 펫, 재료·룬 드랍.

## 7. 이전 1-2 계획에서 바뀌는 점
| 이전(히어로) | 지금(타워) |
|---|---|
| 기본 캐릭터 5종 = 5가지 잼 | 기본 탑 5개 = 5가지 잼 |
| 캐릭터 레벨·스탯·장비 | 탑 레벨·스탯 (룬 소켓은 추후) |
| 영웅 구매/장착 = 퍼즐 잼 종류 | 탑 구매/장착 = 퍼즐 잼 종류 (추후) |
| 타워·바리케이드(추후) | 탑이 핵심. 바리케이드는 "성벽"(HP, 실패 조건)으로 바로 들어감 |
| 실패: 파티 HP 0 | 실패: 성벽 HP 0 |
| 특수 잼 = 콤비네이션·특수 기술 | 지금은 지운 잼 수로만 반영, 기술은 업그레이드(6장) |

## 8. 아트 영향
**그대로 쓰는 것**: 보드 잼 에셋 전부, 25색 팔레트, `ART_DIRECTION.md` 규칙(외곽선 #0d0a10, 크기 등급 16/24/32, 2배 표시).

**지금 필요한 것**
- 탑 5개: 크기 M(16x24), 돌 받침 + 위에 그 색 잼 모양 수정. 대기(빛 맥동 4프레임), 발사(6프레임).
- 투사체 5종(색마다 작은 빛 조각 하나, 2~4프레임).
- 성벽(이어 붙이는 타일 + 부서짐 단계 3장), 배경(길) 1장.
- 적: 오크·슬라임·고블린의 Walk, Attack(성벽 공격), Hit, Death. 히어로용 대기·스킬 동작은 필요 없음.
