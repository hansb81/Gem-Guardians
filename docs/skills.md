0. 구조
기술은 두 층이다.

핵심 기술 = 색 효과 (5개): 그 색 탑이 쏘는 모든 투사체와 기술 피해에 붙는다.
특수 잼 기술 (4개: 가시, 용암탄, 영혼 불꽃, 궁극기): 특수 잼이 터질 때 전장에서 따로 발동한다. 기술 모양은 특수 잼 종류가, 효과는 그 특수 잼의 색이 정한다. 예: 파랑 폭탄 잼 → 냉기 폭발(범위 피해 + 감속), 노랑 라인 잼 → 번개 가시(단일 큰 피해 + 경직).
여기에 보스 면역·약점이 색 효과를 막거나 키운다. 모든 효과는 T2의 onShot / onHit 훅 하나로 처리한다.

가시 규칙 (낙하 기둥 규칙 승계)

대상: 가장 앞(성벽에 가장 가까운) 적 1마리. 오버킬 방지 예약(pendingDamage)은 기본 사격과 같은 방식.
피해: 공격력 × 2.5 − 방어, 최소 1. 색 효과 적용.

연출: 적 발밑 땅에서 가시가 솟았다가 부서진다(bottom-center, 16x32 정도, 6프레임). 솟는 프레임에 피해 + 넉백. 석상 쪽 연출 없음.
라인 잼 두 개가 한 번에 터지면(가로+세로 조합 등) 가시도 두 번: 두 번째 가시는 그 다음 앞 적에게.
다른 기술 연출 (적 쪽에서만)

용암탄: 착탄 지점 위에서 투사체(기존 projectile_{색})가 수직 낙하 → 바닥 타원형 폭발 시트 + 불씨 파티클. 석상에서 날아가지 않는다.
영혼 불꽃: 기존 box_soul_{색}이 성벽 가장자리(전투 길 왼쪽 끝, 대상의 줄 높이)에서 출발해 유도 비행. 궤적은 파티클.
궁극기: 마법진 없음. 전투 영역 화면 번쩍(코드 fillRect) + 모든 적에 명중 번쩍 + 색 효과. 옐로우만 적마다 pixelBolt 한 줄.
공통 명중 번쩍 시트 1장(16x16, 3프레임)을 가시·영혼 불꽃·궁극기가 같이 쓴다.

같은 색 효과가 여러 번 들어와도 위 규칙(감속 갱신, 독 3중첩, 경직 2초 쿨, 표식 2초 쿨·최대 2)을 따른다.
무지개 궁극기는 색 효과의 강화판(위 표 그대로): 레드 = 모든 적 직격이라 범위 없음, 블루 = 감속 ×0.5 3초, 퍼플 = 독 3중첩 즉시, 옐로우 = 경직(보스 제외), 그린 = 표식 2중첩 즉시(쿨타임 없음). 대폭발은 이 강화판 다섯 개를 전부 건다(보스 면역 색 제외).
대폭발 공격력 = 다섯 탑 공격력의 평균 × 2.0 (색이 없으므로).
레드 면역: 면역인 적은 범위 피해를 안 받는다. 직격 대상이 레드 면역이면 그 사격의 범위 폭발 자체가 안 터진다(보스를 직격하면 호위에게 범위가 안 번짐 = 면역의 실제 손해).
조합(변환)으로 생긴 특수 잼은 기술을 쏘지 않는다. 기술은 플레이어가 맞바꾼 특수 잼 2개(또는 단독 발동 1개)에서만 나간다. 예: 라인+컬러 = 가시 1번 + 궁극기 1번, 변환된 라인 잼들은 퍼즐 효과와 기본 사격에만 더해진다. 폭탄+폭탄 = 용암탄 1번(큰 폭탄은 퍼즐 범위만 큼), 박스+박스 = 영혼 불꽃 4개. 이유: 변환된 잼마다 가시가 나가면 한 번에 ×2.5가 7~10번이라 너무 세다. 합체 기술은 나중.
특수 잼끼리 조합(라인+폭탄 등)의 합체 기술은 나중. 지금은 맞바꾼 두 특수 잼의 기술이 따로 발동(라인+라인 = 가시 2번).
무지개 + 무지개 (퍼즐: 보드 전체 삭제): 고를 색이 없으므로 궁극기 규칙만으로는 정의가 안 된다. 따로 둔다 → 대폭발: 모든 적에게 공격력 × 2.0 + 다섯 색 효과 전부(범위 폭발·감속·독 3중첩·경직·표식 2중첩). 보스는 면역인 색만 빠진다. 거기에 보드 전체가 지워지며 나가는 기본 사격까지 더해져서 사실상 "판 정리" 한 방이다. 데이터: specialSkills.color_color = { type: "ultimate", mul: 2.0, target: "all", colors: "all" }.
3. 보스 면역·약점
보스마다 면역 1개 + 약점 1개(마지막 보스는 면역 2개).

면역: 그 색의 부가 효과만 무시한다. 피해는 정상으로 들어간다. 그래서 특정 색만 키운 플레이어도 막히지는 않고, 느려질 뿐이다.
레드 면역 = 범위 피해를 안 받음(직격은 받음), 블루 = 감속 무시, 퍼플 = 독 안 걸림, 옐로우 = 경직 무시, 그린 = 표식 안 붙음.
약점: 그 색 피해 +30%.
넉백 면역: 몸집 큰 보스는 가시에 밀리지 않는다(피해는 들어감).
공통 보스 규칙: 면역이 아니어도 감속 효과 절반(×0.85), 경직 절반(0.2초). 독·표식은 정상.
