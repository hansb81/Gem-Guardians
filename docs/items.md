# 하단 장착 아이템 기획 v2

작성 2026-11-06 · v2 같은 날: 6장 결정 반영(쑹) · v3 같은 날: 6장 7~16 구현 세부 확정, 1차 6개 구현 프롬프트 `plan/items/prompt-claude-code-items.md` · 기준 문서: `plan/skills/gem-skills-proposal-v3.md`, `plan/balance/balance.md`, `plan/balance/config/obstacles.json`

## 0. 원칙

1. **특수 잼 기술과 겹치지 않는다.** 적에게 직접 큰 피해를 주는 아이템(낙뢰, 운석 등)은 만들지 않는다. 피해는 탑(=퍼즐)이 담당하고, 아이템은 **보드 조작 / 시간·성벽 / 경제**만 맡는다.
2. **아이템으로 지운 잼도 "지운 잼"이다.** 지운 색 개수만큼 그 색 탑이 쏜다(퍼즐 규칙 그대로). 그래서 망치·낫도 간접적으로 공격이 되지만, 기술(가시·용암탄 등)은 그 칸에 특수 잼이 있을 때만 나간다.
3. **조준 중에는 전투가 엄청 느려진다(×0.1).** 아이템 버튼을 누르면 보드가 어두워지고 칸/줄을 고르는 동안 전투만 0.1배속(완전 정지 아님). 퍼즐 연쇄는 정상 속도로 마저 진행. 취소하면 소모 없음.
4. **스왑 1회로 치지 않는다.** 아이템 사용은 시한폭탄 타이머·방해요소 생성(everyMoves) 카운트에 들어가지 않는다. 단, 아이템으로 생긴 매치·연쇄는 평소처럼 처리.

## 2. 하단 슬롯

- **슬롯 3칸으로 시작**, 4번째 칸은 20층 보스 처음 클리어 시 열림(또는 다이아로 바로 열기). 5칸 이상은 7x7 보드 폭에서 버튼이 작아져서 비추천.
- 장착은 메뉴(층 시작 전)에서 인벤토리 → 슬롯으로. 층 진행 중에는 바꿀 수 없음.
- 같은 아이템 중복 장착 불가(가로 낫과 세로 낫은 다른 아이템이라 둘 다 가능).
- 버튼 표시: 아이콘 + 남은 개수 숫자 + 쿨다운 중이면 어둡게 + 남은 스왑 수.

## 3. 사용 제한 (개수 + 쿨다운)

인벤토리에 있는 개수만큼 쓸 수 있고, 남용 방지로 **스왑 기준 쿨다운**을 둔다(전투가 실시간이어도 퍼즐 템포에 맞추는 게 더 공정함).

| 아이템 | 쿨다운 | 층당 최대 |
|---|---|---|
| 망치, 염료 | 스왑 2회 | 제한 없음 |
| 가로/세로 낫, 교환 장갑 | 스왑 4회 | 3 |
| 무지개 결정, 섞기 부적 | 스왑 6회 | 2 |
| 수리 망치, 결계, 모래시계 | 스왑 6회 | 2 |
| 분노의 북 | 효과 끝난 뒤 스왑 6회 | 2 |
| 해제 부적 | 스왑 4회 | 2 |

- 보스층은 "층당 최대"가 같다(보스에서 더 쓰고 싶게 만들면 결국 다이아 결제 압박이 됨).
- 층 시작 시 쿨다운은 0(바로 사용 가능).
- 쿨다운의 "스왑"은 유효 스왑만 센다(교환 장갑 스왑·아이템 사용은 안 셈).
- 장착하지 않은 아이템은 쓸 수 없다.
- **예약 사용(낫·망치)**: 고른 줄(칸)에 아직 연출 중인 칸이 있으면 바로 실패하지 않고 대기한다. 그 줄이 전부 한가해지면 그때 실행·소모·쿨다운. 1.5초(`reserveSec`) 안에 안 되면 취소(소모 없음). 대기 중엔 다른 아이템을 쓸 수 없고 스왑은 평소대로. 대기 중인 줄은 깜빡여 표시.

## 4. 획득·가격

**골드는 탑 레벨업의 주 소비처**라서 아이템에 너무 많이 쓰게 하면 성장 곡선(T3·T4)이 흔들린다. 그래서:

- **상점(골드)**: 값이 층에 따라 오른다. `가격 = round(goldBase × 기준 층 보상)`. 기준 층 = 최고 도달 층 이하에서 가장 가까운 순수 일반층(보스·엘리트층 제외), 기준 층 보상 = 그 층의 실제 처치 골드 합 + 다시 깬 층 클리어 보너스(×0.3). 같은 층이면 항상 같은 값. 이렇게 하면 어느 층에서나 "몇 층 분량의 골드"로 체감 값이 일정.
- **상점(다이아)**: 고정가 묶음(5개/10개). 부활·황금 주화·4번째 슬롯은 다이아 전용.
- **무료 획득**: 보스 첫 클리어 보상(1차: 서로 다른 아이템 2개, 층 번호 seed), 출석 달력, 이벤트, 일일 무료 1개(광고 붙일 자리).

| 아이템 | 골드 기준가 (1층 기준, ≈ 일반 층 N개 분량) | 다이아 |
|---|---|---|
| 망치 | 일반 층 1개 분량 | 5개 묶음 20 |
| 염료 | 일반 층 1개 | 5개 묶음 20 |
| 가로/세로 낫 | 일반 층 2개 | 5개 묶음 35 |
| 교환 장갑 | 일반 층 2개 | 5개 묶음 35 |
| 무지개 결정 | 일반 층 4개 | 5개 묶음 60 |
| 섞기 부적 | 일반 층 1개 | 5개 묶음 15 |
| 수리 망치 / 모래시계 / 결계 | 일반 층 3개 | 5개 묶음 50 |
| 해제 부적 | 일반 층 2개 | 5개 묶음 30 |
| 분노의 북 | 일반 층 3개 | 5개 묶음 50 |
| 시작 부스터 | 일반 층 3개 | 3개 묶음 30 |
| 황금 주화 / 부활 | 다이아 전용 | 1개 30 / 1개 50 |

숫자는 시작값이다. 시뮬레이터에 "아이템 사용" 봇 옵션(T5)을 넣어 보스 재시도 횟수가 얼마나 줄어드는지 보고 맞춘다. 목표는 **아이템을 쓰면 보스 재시도 1회 정도 줄어드는 수준**(필수가 아니라 편의).

## 6. 결정 (2026-11-06 쑹)

1. 아이템으로 지운 잼은 **탑 사격으로 이어진다** (지운 색 개수만큼, 일반 매치와 같음)
2. 낫·망치로 특수 잼을 지우면 **특수 잼이 터진다** (퍼즐 효과 + 특수 잼 기술 발동)
3. 조준 중 전투는 **엄청 느리게** (×0.1, `config/items.json`의 `targetingBattleTimeScale`)
4. **1차는 6개**: 망치, 가로 낫, 세로 낫, 무지개 결정, 교환 장갑, 수리 망치, 모래시계 (낫 가로/세로를 한 묶음으로 셈). 염료·섞기·결계·해제·분노의 북·C그룹은 2차
5. 망치·낫으로 지운 칸에 시한폭탄이 붙어 있으면 해제. 나무상자·돌덩이는 각 1 피해(`damagedBy`에 `item`)
6. 대상 칸이 바쁘면 사용 실패(소모 없음). 단 낫·망치는 3장 "예약 사용"

### 구현 세부 확정 (2026-11-06 쑹, 1차 구현 후)

7. **가격** = 실제 층 보상 기준(4장, 보스·엘리트층 제외). `goldGrowth` 공식은 쓰지 않는다
8. **보스 첫 클리어 보상** 2개는 서로 다른 아이템(seed RNG, 중복 없음)
9. **무지개 결정**은 시한폭탄 잼에도 사용 가능(A4)
10. **모래시계**: 정지 중 새로 나온 적도 멈춤, 상태 효과 시간은 흐름(B2)
11. **콤보**: 망치·낫은 콤보 스트릭·HUD 연쇄 수를 올리지 않는다. 교환 장갑으로 생긴 매치는 평소 스왑처럼 콤보에 들어간다
12. **이벤트 연출 길이**: `wallHealed` 400ms, `enemiesFrozen`/`enemiesUnfrozen` 300ms(`src/config/battle.json`)
13. **장착 확인**: 장착 안 된 아이템은 사용 실패(`notEquipped`)
14. **옛 저장 데이터**(아이템 정보 없음)는 처음 시작처럼 지급: 각 아이템 3개 + 기본 장착 [가로 낫, 망치, 수리 망치]
15. **교환 장갑**으로 매치 없이 바꾼 뒤 둘 수 있는 수가 없으면 즉시 재배치
16. **예약 사용**: 낫·망치 대상이 바쁘면 1.5초까지 대기(3장). 보드 밖 대상은 대기 없이 즉시 실패(`invalidTarget`)

## 7. 아트 (나중에)

아이콘만 필요: 16x16 네이티브, 기존 팔레트, 알파 0/255, 아이템당 1장(애니 없음). 사용 연출은 기존 에셋·파티클 재사용(망치 = 명중 번쩍 + 파편, 낫 = 줄 따라 pop 이펙트, 모래시계 = 전투 영역 회색 틴트, 결계 = 성벽 앞 코드 사각형 깜빡임).
