## 0. 원칙

1. **수호자 1명 = 정령 1마리.** 전투에서는 등급과 상관없이 전부 원본 10x10, 수호자 줄의 **바깥쪽**에 둔다(왼쪽 줄 = 왼쪽 바깥, 오른쪽 줄 = 성벽 쪽). 위아래 둥실(±1px)은 코드.
2. **정령은 그 수호자가 쏠 때만 움직인다.** 자동 공격 없음. (보조 역할만 예외: 장착하면 항상 켜짐)
3. **특수 잼 기술·아이템과 겹치지 않는다.** 정령은 일반 사격을 조금씩 다르게 만든다.
4. **연출은 적 쪽에서만.** 수호자·정령에서 적까지 이어지는 빔 없음.
5. **힘의 상한.** 5마리를 전부 최고로 키워도 전체 전력 +25~35%. 정령 없이도 100층 가능. 시뮬레이터 기본값은 "정령 없음".

## 1. 확정한 것 (v1의 "쑹이 정할 것")

| 항목 | 확정 |
|---|---|
| 등급 | 종마다 고정(일반·희귀·영웅·전설). 합성 없음. 중복 = 각성(별 1~5) |
| 종 수 | 30종 = 속성 5 × (일반 2 · 희귀 1 · 영웅 1 · 전설 1) + 보조 5(속성당 1, 희귀) |

| 전투 크기·자리 | 전부 10x10, 바깥쪽 배치. 큰 모습(초상)은 정령 탭·상점에서만 |
| 영웅 등급 | v1의 "보조 효과 1개 추가"는 뺀다. 배율만 높음 |
| 콤보 정령 | 없음(콤보는 연출 전용) |

## 2. 효과 계산

`효과 배율 = 등급 × (1 + 0.01 × (레벨 − 1)) × (1 + 0.05 × (별 − 1)) × 공명`

| | 값 |
|---|---|
| 등급 | 일반 1.0 · 희귀 1.2 · 영웅 1.4 · 전설 1.6 |
| 레벨 1~30 | 레벨당 +1% (30레벨 ×1.29) |
| 별 1~5 | 별당 +5% (별 5 ×1.2). 별 3·5에서 "N발마다"가 1씩 줄어듦(최소 2) |
| 공명 | 정령 속성 = 수호자 색이면 ×1.25 |

최대(전설·30레벨·별 5·공명) = ×3.1. 일반 기본 효과가 전력 +3% 안팎이라 정령 1마리 최대 +9% 안팎, 5마리 합 +25~35%가 목표다. v1 숫자(등급 ×3.0, 레벨 +3%, 공명 ×1.5)는 곱하면 ×11이 넘어서 버렸다.

## 3. 역할 (기본값 = 일반 등급, 배율 1.0일 때)

| 역할 | 규칙 | 기본값 |
|---|---|---|
| 공격 `attack` | 그 수호자가 N발 쏠 때마다 정령이 추가 1발(가장 앞 적, 예약 피해 방식 동일). 피해 = 수호자 공격력 × mul × 배율 − 방어. 색 효과·기술 없음 | N 3, mul 1.2 |
| 속성 `element` | 그 수호자가 쏠 때 확률로 발동: 그 발의 피해 +50%(방어 계산 전, 배율 없음) + 명중하면 **정령 속성**의 색 효과 1회(색 효과가 잠겨 있으면 피해 증가만) | 확률 30% × 배율 (상한 75%), procDmg 0.5 |
| 증폭 `amplify` | **모든 색** 특수 잼 기술 피해 증가(여러 마리면 더한다, 색 없는 대폭발 제외). 공명은 정령 속성 = 장착한 수호자 색 | +25% × 배율 (`allColors` true) |
| 수호 `guard` | 그 수호자가 적을 처치하면 성벽 회복 | 최대 HP의 2% × 배율, 층당 합계 상한 25% |
| 재물 `wealth` | 그 수호자가 처치한 적의 처치 골드 증가(클리어 보너스·콤보 골드 계산에는 안 들어감) | +20% × 배율 |
| 보조 `support` | 장착하면 항상 켜짐. **같은 보조 효과는 겹치지 않고 가장 높은 것만** | 아래 표 |
| 고유 `unique` | 전설 전용 규칙 | 5장 |

**처치 판정**: 마지막 피해를 준 쪽. 일반 사격 = 그 수호자, 특수 잼 기술 = 그 잼 색 수호자, 독·범위 = 그 효과를 건 색의 수호자. 알 수 없으면 아무에게도 안 줌.

**보조 5종 (희귀, 속성당 1)**

| id | 속성 | 효과 (배율 적용) |
|---|---|---|
| `sup_cascade` 연쇄 정령 | 불 | 연쇄 2단계부터 단계당 피해 보너스 +1.5%p |
| `sup_clock` 시계태엽 정령 | 얼음 | 시한폭탄이 생길 때 타이머 +1 (배율 무시, 고정) |
| `sup_breaker` 해체 정령 | 숲 | 매치 옆 방해요소에 12% 확률로 1 추가 피해 |
| `sup_paint` 물감 정령 | 독 | 새로 떨어지는 잼이 **장착한 수호자의 색**일 확률 +3%p (상한 +8%p) |
| `sup_tinker` 망치 정령 | 번개 | 그 수호자가 12발 쏠 때마다 하단 아이템 쿨다운 전부 −1 스왑 |

## 6. 성장·획득

- **레벨업**: 골드 = 일반 층 보상 × 0.06 × 1.04^(레벨−1), 정령석 = ceil(레벨 / 3). 최대 30. (v13-8, 2026-11-28: 0.25 × 1.06에서 내림 - 정령 레벨업이 탑보다 손해인 골드 함정을 줄이고, 레벨업 상한은 정령석이 맡는다.)
- **각성**: 같은 정령을 또 얻으면 별 +1(최대 5). 별 5 이후 중복은 정령석으로(일반 5 · 희귀 10 · 영웅 20 · 전설 50).
- **정령석**: 보스 첫 클리어 +5(50층 이상 +10), 위 중복 변환. 매일 얻는 길(docs/spirit-stones.md):
  - 광산 용광로 정제: 하루 3개, 원석 60 / 120 / 240(`config/mine.json` `stones`, docs/mine.md 19장). 정령이 없어도 정제된다.
  - 출석: 7일째 보상과 7일 연속 보너스에 정령석 5씩(겹친 날 10, docs/attendance-streak.md 5장).
  - 상점 정령석 묶음: 정령석 5 = 다이아 40, 하루 1번(KST). 다이아 레일 "다이아 전용" 칸(`config/shop.json` `diaItems`의 객체 칸, txId `shop:stones:{날짜}`).
  - 레벨업 버튼에서 정령석이 모자라면 버튼 위에 "광산에서 정제 / 상점에서 구매" 두 줄(이동 버튼 없음).
- **지금 얻는 길**(뽑기·판매 없음): 처음 시작 = 도깨비불 1. 보스 첫 클리어 = 10·20층 일반, 30·40층 희귀, 50층 영웅, 60층 이후 = 일반 55 / 희귀 30 / 영웅 13 / 전설 2 가중 무작위(층 seed). dev 패널 = 전부 지급.
- **나중**: 속성 알·소환(뽑기). 확률 70/22/7/1, 천장 60/120. 한국 게임산업법 확률 공개 의무 + 스토어 정책 때문에 확률표 화면이 같이 나가야 한다.
- 장착 변경은 무료. 층 진행 중에 바꾸면 다음 층부터 적용(하단 아이템과 같은 규칙).

## 7. 화면

- 강화 팝업 탭 `수호자 / 정령 / 보관함`(토템 탭 자리, 잠금 해제).
- 정령 탭(2026-11-27 바꿈): 위 = 수호자 무대 5칸 가로 한 줄(30x34 x3, idle 수호자 + 어깨 옆 정령, 공명이면 밝은 빛 + "공명") + 고른 수호자 정보 카드(이름 + 정령 이름, 효과 한 줄, "해제"). 무대를 누르면 그 수호자 선택, 아래 = 정령 목록(속성·등급 필터, 5열, 칸 86x92 고정, 세로 스크롤) + 상세(이름, 등급, 레벨, 별, 효과 수치, 레벨업 버튼, 장착/해제).
- 전투: 0번 원칙의 자리. 효과가 발동할 때 정령이 1회 번쩍.
- 목록·도감(2026-11-24, 상점 정령 레일에서 옮겨 하나로 합침): 정령 탭 목록 위 오른쪽 "보유 n / 30"(항상), 그 아래 같은 폭 필터 버튼 3개 - 속성(전체 → 불 → 얼음 → 숲 → 독 → 번개, 잼 미니 아이콘 + 이름), 등급(전체 → 일반 → 희귀 → 영웅 → 전설, 등급 색 글자), 보유("보유만"(기본) ↔ "전체"). 누를 때마다 다음 값, 길게 누르면 그 필터만 전체로, 전체가 아닌 값이면 slot_selected 틀. 목록은 하나(config 순서): 보유 "전체"면 안 가진 정령이 #221c2b 실루엣으로 섞인다(칸 테두리는 가진 정령과 같은 등급 색). 가진 정령을 누르면 상세(레벨업·장착), 안 가진 정령은 도감 설명(이름·등급·속성·역할·1레벨 기준 효과, 버튼 없음). 상세·설명은 칸 오른쪽 위 X로 닫는다("목록" 버튼 없음). 결과가 없으면 "조건에 맞는 정령이 없어요". 상점에는 정령 레일이 없다(판매가 생기면 다시 검토).
- 그림(완료): 전투 = `assets/spirits/spirits.png`(40x300, 정령마다 한 줄 10x10 4프레임), 초상 = `portraits.png`(24x24, 6열), 정령석 = `assets/ui/icons/spirit_stone.png`. 줄·칸 번호는 `assets/spirits/manifest.json`. 등급 테두리 색 = 일반 #655a74 · 희귀 #386cbc · 영웅 #7a3cae · 전설 #f2d264.
