# 튜토리얼 기획 v1 (최초 인게임 진입)

목업: `art/tutorial/mockups/storyboard.png` (단계별 `step_01~11.png`) · 에셋: `gem-guardians-tutorial.zip` → `assets/ui/tutorial/`
구현 프롬프트: `plan/tutorial/prompt-claude-code-tutorial.md`

## 0. 언제, 어떻게
- **처음으로 인게임(1층)에 들어갈 때 한 번.** 저장 데이터 `tutorial.done !== true`이면 실행.
- 1층 진입 → 석상 소환 연출(기존) → 튜토리얼 시작. 웨이브는 튜토리얼이 끝날 때까지 멈춘다(적 생성 없음, 성벽 피해 없음).
- 중간에 앱을 끄면 다음 진입 때 **처음부터** 다시(단계 저장 안 함, 단순하게).
- 스킵: 화면 오른쪽 위 **건너뛰기** 버튼(튜토리얼 중엔 일시정지 버튼 자리). 누르면 확인 팝업 → 건너뛰면 바로 4장 마무리(셔플 → 웨이브)로.
- "1층 진입" 조건은 **최초 자동 실행에만** 쓴다. 다시 보기는 별도 연습 모드(5장).
- 저장: `tutorial: { done, version: 1 }`. tutorial 필드가 없는 예전 세이브는 플레이 흔적(최고층 > 1, 진행 층 > 1, 석상 레벨 > 1, 골드·다이아 > 0) 중 하나라도 있으면 `done: true`로 넣는다. 완전히 새 세이브만 자동 실행된다.
- 튜토리얼 동안 콤보(연속 스트릭)를 쌓지 않고 콤보 UI도 안 뜬다. 끝/스킵 때 콤보를 조용히 0으로(“Combo xN Break!” 없음).

## 1. 화면 구성 공통
- **딤 + 스포트라이트**: 화면 전체를 `#0d0a10` 72% 로 어둡게, 설명 대상 영역만 구멍(코드로 그림). 구멍 테두리에 `hl_frame`(9-slice) 400ms마다 `hl_frame_b`와 교대.
- **안내 말풍선**: `guide_box`(9-slice) + 왼쪽 위 `portrait_frame` 안에 화자 **봉인의 정령**(`guide_spirit` 4프레임). 제목은 금색 `#f2d264`, 본문 `#e8dcc0`, Galmuri11. 오른쪽 아래 `next_tri` 깜빡 = 탭해서 계속.
- 말풍선은 대상과 겹치지 않게: 대상이 화면 위쪽이면 아래에, 아래쪽이면 위에.
- 화면 가장자리 대상(재화 바 등)은 구멍을 화면 안으로 잘라 테두리가 보이게 한다.
- 스텝이 바뀔 때 구멍은 200ms ease-out으로 옮겨 간다. 구멍 **개수**가 바뀌면 이전 묶음의 바깥 rect → 새 묶음의 바깥 rect를 구멍 하나로 보간한 뒤 실제 구멍들로 바꾼다(구멍이 없던 쪽은 상대 묶음 가운데의 크기 0 rect).
- `arrow`는 `config/tutorial.json` 스텝마다 켜고 끈다. 지금은 재화 바·층·건너뛰기 버튼·성벽 게이지.
- 설명 단계: **아무 곳이나 탭 = 다음**(나타난 뒤 0.4초 동안은 무시해서 연타로 넘어가지 않게). 글자는 타자 효과(30ms/글자), 타자 중 탭 = 전체 표시.
- 레슨 단계: 안내한 스왑만 받는다. 다른 입력은 무시하고 손가락을 한 번 더 크게 보여준다.

## 3. 레슨 (몬스터 → 퍼즐 → 유저 행동 → 몬스터 처치)
공통 진행:
1. 레슨 보드를 깐다: 기존 셔플 애니메이션(위에서 떨어짐)으로 **미리 정한 보드**(`boards.json`)를 채움.
2. 몬스터 1마리(1층 일반 몬스터, 예: 고블린)가 오른쪽에서 걸어 들어와 전장 가운데(성벽까지 거리의 60% 지점)에서 **멈춘다.** 튜토리얼 몬스터는 성벽을 공격하지 않음, 골드/드롭 없음.
3. 딤: 전투 패널 + 이번 수에 관련된 칸만 밝게. 바꿀 두 칸에 `cell_mark`, 두 칸 사이에 `swap_arrow`, `hand`가 시작 칸에서 끝 칸으로 끌기를 반복(누름 → 0.5초 이동 → 뗌 → 0.4초 쉼, 누를 때 `tap_ring`). 위쪽 점수줄 자리에 `pip` 4개(완료=초록, 현재=금, 남음=빈칸).
4. 유저가 안내대로 스왑 → 평소 퍼즐 처리(매치/특수 잼 생성/낙하). 리필은 **바로 매치가 안 생기는 젬만**(noMatch 리필) — 레슨 중 우연한 연쇄 방지.
5. 석상 공격 → 몬스터 처치 → 0.6초 후 "잘했어요!" 짧은 말풍선(1초, 탭 불필요) → 다음 레슨.

몬스터 HP 규칙(일반 매치 = 기본 피해만):
- 레슨 1: HP = 1 → 매치 한 번에 반드시 죽음.
- 레슨 2~4(특수 잼은 **만들기 → 쓰기** 2수): HP = 1, `hpFloor:1`로 HP 1 아래로 안 내려감. 만들기 수의 공격은 맞는 연출만 하고 버틴다. **쓰기 수에서는 특수 잼 기술 피해만 hpFloor를 뚫는다**(일반 매치 사격이 먼저 끝내서 기술이 빈 동작이 되지 않게). 쓰기 수 뒤 보드가 멈추고 날아가는 공격도 없는데 2초가 지나도 살아 있으면 안전장치로 강제 처치. 처치 수에선 피해 숫자를 평소대로 표시.
- 기술 임시 해금: 신규 플레이어는 용암탄(폭탄)·영혼 불꽃(박스)이 상점 해금 전이라 잠겨 있다. 튜토리얼 동안만 메모리의 전투 기술 설정을 해금본으로 덮고(세이브엔 안 씀), 완료·스킵·중간 이탈 어느 경로든 원래 값으로 돌린다(앱을 끄면 저장된 적이 없으니 자연히 원래대로).
- 튜토리얼 몬스터 = 1층 지역(`enemies.json` chapters[0].pool)의 첫 번째 몬스터.
- 레슨 딤: 쓰기 단계에서는 특수 잼 칸도 밝힌다(boards.json highlight에 없어도). `cell_mark`는 정수 배율 `max(1, floor(칸px / 32))`로 칸 가운데에.

| 레슨 | 몬스터 | 1수: 만들기 | 2수: 쓰기 | 말풍선 |
|---|---|---|---|---|
| 1 3매치 | 1마리 | (4,4)빨강 ↓ → 5행 빨강 3개 | — | 손가락을 따라 빨간 젬을 밀어 빨간 젬 3개를 맞춰 보세요! |
| 2 라인 | 1마리 | (4,3)파랑 ↓ → 5행 파랑 4개 → 라인 젬 (5,3) | (4,4)파랑 ← → 3열 파랑 3개(라인 포함) → 가시 | ① 같은 색 4개를 한 줄로 맞추면 라인 젬이 생겨요. ② 라인 젬을 같은 색과 맞추면 한 줄을 지우고 가시가 솟아요! |
| 3 폭탄 | 1마리 | (5,5)빨강 ← → 5행 3개 + 4열 3개 L자 → 폭탄 (5,4) | 폭탄 ↓ (6,4) → 6행 빨강 3개 → 용암탄 | ① 가로와 세로를 함께 맞추면(L, T) 폭탄 젬! ② 폭탄 젬을 같은 색과 맞추면 주변이 폭발하고 용암탄이 떨어져요! |
| 4 박스 | 1마리 | (5,4)초록 ← → 2x2 초록 → 박스 (5,3) | 박스 ↓ (6,3)과 바꾸기 → 영혼 불꽃 | ① 같은 색 4개를 네모로 모으면 박스 젬! ② 박스 젬은 아무 젬과 바꿔도 터지고, 영혼 불꽃이 날아가요! |

좌표는 (행, 열), 0부터, 위 왼쪽 기준. 보드 4개는 `art/tutorial/boards.py`로 검증함: 처음 보드에 매치/2x2 없음, 안내 스왑이 의도한 모양만 만듦, 낙하 후 우연한 매치 없음(새 젬은 noMatch), 쓰기 수가 특수 잼을 정확히 터뜨림.
컬러(무지개) 젬은 넣지 않았다(요청 범위 밖, 웨이브에서 자연스럽게 발견). 원하면 레슨 5로 추가 가능.

## 4. 완료 → 셔플 → 웨이브
- 마지막 레슨의 "잘했어요!"(처치 0.6초 후 1초)가 끝나고 0.8초 뒤 완료 팝업: `popup_win`(9-slice) + `emblem_done` + `btn_gold`.
  - 제목 **튜토리얼 완료!** / 본문 "이제 진짜 수호가 시작됩니다. 석상을 강화하며 깊이 내려가세요!" / 버튼 **전투 시작**
  - 보상(선택, 설정값): `rewardGold` 기본 100, 인벤토리 grant 모듈 txId `tutorial_complete`로 한 번만. 스킵하면 보상 없음.
- 확인 → `tutorial.done=true` 저장 → 팝업 닫힘 → **셔플 1회**(기존 셔플 애니메이션, 새 랜덤 보드) → 웨이브 1 시작(평소 1층 흐름, 건너뛰기 버튼 → 일시정지 버튼).

## 5. 스킵 · 다시 보기(연습 모드)
- 어느 단계에서든 건너뛰기 → 확인 팝업 `popup_pause` + `emblem_pause`: **건너뛸까요?** / "설정 > 도움말에서 다시 볼 수 있어요." / [건너뛰기(secondary)] [계속 보기(primary)].
- 팝업 동안 튜토리얼 타이머·손가락·몬스터 걷기 정지. 건너뛰기 → 튜토리얼 몬스터 제거, `done=true`(보상 없음), 4장의 셔플 → 웨이브 1.
- **다시 보기 = 독립 연습 모드.** 메인 메뉴 설정 > 도움말 화면 아래의 "튜토리얼 다시 보기"를 누르면 다음 전투를 기다리지 않고 바로 튜토리얼 전용 전투를 연다.
  - 층 데이터는 1층(HUD도 1층). 진행 중인 층·웨이브·골드·세이브는 건드리지 않는다: 보상 없음, 예약 아이템 소모 없음, 통계·랭킹 기록 없음, `done` 값 변경 없음.
  - 끝나면 완료 팝업 버튼이 **메인 메뉴로**(그 외 문구 동일), 스킵하면 바로 메인 메뉴로. 셔플·웨이브 없이 메뉴로 돌아가고 원래 층은 처음부터.
  - 인게임 설정(일시정지 팝업)에서는 버튼을 비활성으로 보여 주고 "메인 메뉴의 설정에서 볼 수 있어요" 안내.
- 개발용(`?dev=1` 패널): "튜토리얼 초기화" = `done=false`(다음 1층 진입 때 자동 실행).
