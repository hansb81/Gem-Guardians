## 3. 문서와 코드가 아직 안 맞는 부분 (구현 TODO)
- **환불 회수**: 현재 코드는 환불 시 adFree만 회수(platform-plan §15). 약관은 "받은 것 전부 회수, 부족하면 다이아 0까지 차감"을 적어 두었으니, 최소한 서버 `refunded` 상태일 때 `refund:{orderId}` tx로 해당 번들을 빼고(0 밑으로 안 감) 반복 시 banned 처리 정도를 v2로.
- **"사용하지 않음" 판정**: 지갑이 로컬이고 유료/무료 다이아가 구분되지 않아서, 지금은 "그 결제로 받은 수량 이상이 남아 있고 구성 아이템이 그대로인지"로 수작업 판단. 관리자 페이지 결제 화면에 해당 플레이어 클라우드 저장 요약(다이아·아이템 수)을 같이 보여 주면 판단이 빨라짐. 장기적으로 유료 다이아 별도 집계(`diaPaid`) 권장.
- **회원 번호 노출**: 설정 > 게임 정보에 복사 가능한 회원 번호 필요(환불 문의용).
- **상품별 철회 제한 표시**: shop-refund-notice ②를 상품 카드/구매 확인에 표시해야 철회 제한이 법적으로 유효함(전자상거래법 제17조 제6항).
- **원스토어 빌드**: 다른 마켓 이름/링크 금지 → 환불 팝업에서 해당 마켓 줄만.
- 확률형(정령석 가챠 등)을 넣으면 약관 제16조대로 확률 표시 페이지 필요.
- 개인정보 처리방침은 별도 문서 필요(이번 범위 밖). 결제 기록 5년 보관, Supabase/RevenueCat 국외 이전 고지 포함.
