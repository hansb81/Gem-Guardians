보관함 시안 B — 가독성 개선안

지금 화면(인벤토리 탭 그대로)과 같은 그림 팩만 쓴다. 칸 44px, 글자 Galmuri11 11/22px.

바뀐 점

  • 이름: 장착·예약 칸만 아이콘 밑에 이름. 보유 칸은 칸만(이름은 고르면 아래 패널에).
  • 보유 칸 스크롤: 최대 20칸(5열 x 4줄), 3줄 반만 보이고 세로 스크롤. 빈 칸도 자리를 그려서 남은 칸 수가 보임.
  • 구역 상자: 장착 / 예약 / 보유를 inset 상자로 나누고 제목은 금색, 보조 정보는 오른쪽.
  • 분류 탭: 보드·전투·기타 소제목 대신 탭(전체/보드/전투/기타) - 한 번에 보이는 칸 수를 줄임.
  • 장착 표시: 이미 꽂힌 아이템은 목록 칸 왼쪽 위에 금색 "E" 표(Equip, 칸이 작아 한 글자). 0개는 흐리게 + 빨간 0.
  • 빈 칸: "+"와 "빈 칸" 글자. 잠긴 칸은 자물쇠 + "잠김".
  • 예약 켜짐: 색만이 아니라 "예약됨/끔" 글자로도 보임.
  • 설명 패널 고정: 아래에 큰 아이콘 + 이름(금) + 설명(뼈색, 줄 간격 1.5, 2줄까지 줄바꿈) + 수치 표(파랑).
  • 행동 버튼: "칸을 누르세요" 안내 대신 고른 아이템에 맞는 버튼(장착 / 해제 / 상점에서 사기).
  • 보조 글자색 #8a8296 → #a59cb2(어두운 바탕 대비 4.5:1 이상).

기획에 없는 것 (결정 필요)

  • 팝업 크기: 지금 최대 340x480 → 화면의 거의 전체(폰 390x844에서 374x772).
  • "장착" 버튼이 넣을 칸 = 첫 빈 칸(없으면 장착 칸을 눌러 바꾸기는 지금처럼 유지).
  • 분류 탭 기억 여부(열 때마다 "전체"로).
