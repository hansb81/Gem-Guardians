# 특수 잼 조합 이펙트 시안 (10종)

`combo_{조합}.gif` = 7x7 보드 시뮬레이션. 스토리보드: `art/effects/combos_storyboard.png`. 생성기: `art/effects/preview_combos.py`.
기존 #1~#5 이펙트만 엮고 조합 전용 시트는 없습니다(GIF의 합쳐짐 번쩍·변신 번쩍·큰 폭탄은 폐기 - 실제 게임과 다름).
두 특수 잼은 한 칸으로 미끄러진 뒤 바로 사라지고, 변신은 번쩍임 없이 그림만 특수 잼으로 바뀝니다.

| 조합 | 연출 |
|---|---|
| 라인+라인 | 합쳐짐 → 가로·세로 빛줄기 동시 (+) |
| 라인+폭탄 | 가운데 폭탄 + 빛줄기 가로 3줄·세로 3줄 |
| 폭탄+폭탄 | 보통 폭탄 4개를 2x2로 동시에 (3x3 네 개가 4x4를 덮음) |
| 컬러+라인 | 무지개 불씨 → 같은 색 잼이 라인 잼(방향 랜덤)으로 변신 → 가까운 것부터 110ms 간격 발사 |
| 컬러+폭탄 | 같은 색 잼 → 폭탄 잼 변신 → 130ms 간격 폭발 |
| 컬러+컬러 | 소용돌이 2개 → 무지개 물결이 가운데부터 보드 전체 (한 칸 55ms) |
| 박스+박스 | 번개 6갈래, 두 박스 색 번갈아 50ms 간격 |
| 박스+라인 / 박스+폭탄 | 번개 2갈래가 그 색 잼 2개를 쳐서 변신 → 차례로 발사/폭발 |
| 박스+컬러 | 같은 색 잼 → 박스 잼 변신 → 하나씩 번개 2갈래 |
