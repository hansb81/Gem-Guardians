# Gem Guardians 잼 에셋 (다크 판타지 픽셀, A 스타일)

압축을 풀어 저장소의 `assets/gems/`에 넣으면 됩니다. 모든 경로는 `manifest.json` 기준 상대경로입니다.

## 규격
- 이미지 48×48 px, 투명 PNG. **잼 몸통은 모든 이미지에서 가운데 32×32에 똑같은 크기로** 들어 있고, 바깥 8px 여백은 효과(균열 끝, 불꽃, 반짝임)만 씁니다.
- 화면에는 2배로 그립니다: 칸은 64px(=몸통 32×2), 이미지는 96px이고 **칸 중심에 맞춰** 그립니다. 효과는 옆 칸으로 살짝 넘어가도 정상입니다.
- 이미지 크기에 맞춰 늘리거나 줄이지 마세요(fit/contain 금지). 항상 같은 배율로 그려야 잼 크기가 일정합니다.
- 캔버스에서 `ctx.imageSmoothingEnabled = false` 필수 (안 하면 픽셀이 뭉개짐).
- 색 키: `red`, `blue`, `green`, `yellow`, `purple`
- 팔레트 25색: `palette.hex` (캐릭터·이펙트도 이 안에서)

## 폴더
| 폴더 | 내용 |
|---|---|
| `normal/{색}.png` | 일반 잼 |
| `line_h/{색}.png` | 가로 줄 잼 (가로로 가르는 빛나는 균열) |
| `line_v/{색}.png` | 세로 줄 잼 |
| `bomb/{색}.png` | 폭탄 잼 정지 이미지 |
| `box/{색}.png` | 상자 잼 정지 이미지 (터지면 랜덤 잼 2개 추가 제거) |
| `color/color.png` | 컬러(무지개) 잼, 색 없음 |
| `sheets/` | 애니메이션 스프라이트 시트 (48px 프레임 가로 나열) |

## 애니메이션 (`manifest.anims`)
| 키 | 프레임 | ms/프레임 | 시트 크기 |
|---|---|---|---|
| `line_h_{색}` | 8 | 100 | 384×48 |
| `line_v_{색}` | 8 | 100 | 384×48 |
| `bomb_{색}` | 6 | 100 | 288×48 |
| `box_{색}` | 16 | 110 | 768×48 |
| `color` | 20 | 100 | 960×48 |

모두 루프. 애니메이션이 있는 잼은 정지 이미지 대신 시트를 그리고, 정지 이미지는 로딩 실패 시 폴백이나 UI 아이콘용으로 씁니다.

```js
// frame = Math.floor(time / a.frameMs) % a.frames
// cx, cy = 칸의 중심 좌표, scale = manifest.drawScale
const w = a.frameW * scale, h = a.frameH * scale;
ctx.drawImage(img, frame * a.frameW, 0, a.frameW, a.frameH, cx - w / 2, cy - h / 2, w, h);
```
같은 종류 잼이 한꺼번에 똑같이 깜빡이지 않게, 잼마다 시작 시간을 랜덤으로 어긋나게(offset) 주는 걸 권장합니다.

## 참고
- 특수 잼은 "기본 잼 + 오버레이"가 아니라 **완성된 이미지 한 장**입니다. 렌더러에서 특수 잼이면 기본 잼 위에 겹치지 말고 해당 이미지로 바꿔 그려 주세요.
- 효과가 옆 칸 잼에 가려지지 않게, 특수 잼은 일반 잼보다 나중에 그리는 걸 권장합니다.
