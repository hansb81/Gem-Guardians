# 타이틀 → 메인 메뉴 문 열림 전환 (확정, v2 배경 구조 기준)

총 2.2초. 터치 직후부터:
| 구간 | 연출 |
|---|---|
| 0 ~ 350ms | 문 안쪽이 금빛으로 차오름 (디더로 밝아짐), 문틈 줄이 흰빛으로 번쩍 |
| 350 ~ 1100ms | 문짝 두 장이 바깥쪽 경첩을 축으로 **안쪽으로 회전**해 열림 (0 → 80도, ease in-out). 원근: 문짝 폭 = 20·cos(각), 자유 끝으로 갈수록 세로가 최대 35% 줄고(문 중앙 y=190 기준으로 수렴) 어두워짐(역광). 자유 끝 세로줄은 흰/금빛. 문짝 = `door_leaf_left.png` / `door_leaf_right.png`(네이티브 20x104, 원본 위치 좌 (70,132), 우 (90,132)) |
| 500 ~ 1100ms | 문 밖으로 빛살이 점점 넓게 퍼짐 |
| 950 ~ 1450ms | 문 안의 빛이 **밖으로 터져 나감**: 문 중심(네이티브 90,190)에서 금빛 원이 디더 가장자리(폭 ~160px 화면)로 커짐. 눈부심 방지: 덮는 비율은 최대 ~55%(3px 디더)라 장면이 비쳐 보이고, 색은 바깥 #7a5212 → #c28a20, 중심만 #f2d264. 흰색 없음. 반지름 = 진행도^0.8 × 1150px |
| 1250 ~ 2200ms | 빛이 퍼지는 동안 바로 메인 메뉴로 크로스페이드 시작 (ease in-out) |

구현 메모
- 타이틀 배경은 v2 구조(`title_base.png` + 조각 + 입자, `manifest.background`)로 전환 중에도 계속 재생. 문 조각(p00)은 문 안쪽 금빛 채움(0~350ms)이 덮으므로 그대로 둬도 됨. 로고/글자는 0~300ms에 사라짐.
- 문짝 두 장은 이미지로 제공: `door_leaf_left.png`(네이티브 (70,132)에 위치), `door_leaf_right.png`((90,132)). 열리는 동안 문 아치 모양(폭 40, 윗부분 반지름 18~20의 아치, (70,132)-(110,236))으로 클리핑.
- 메인 메뉴 배경도 같은 v2 구조(`menu_base.png` + 조각 + 불씨)로, 크로스페이드가 시작되는 1250ms보다 먼저 시작해 두면 끝에서 자연스럽게 이어짐.
- 문짝 회전은 세로 1px 열(column)마다 `drawImage`로 높이를 바꿔 그리면 됨(열 수 = 20·cos(각)).
- 사운드 자리: 0ms 돌 긁힘, 350ms 묵직한 문 열림, 900ms 상승음.
- 생성기: `art/title/door_transition.py` → `door_transition.gif`, `door_transition_keys.png`
