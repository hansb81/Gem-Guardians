# Credits

Gem Guardians에 쓰인 외부 에셋과 그 라이선스 기록이다. 외부 에셋을 추가하면 여기에 한 줄씩 남긴다.

## 몬스터 스프라이트 (`assets/enemies/`)

모든 프레임은 게임 팔레트에 맞게 색을 바꿨다. 원본 라이선스는 둘 다 CC0라서 상업적 사용, 수정, 재배포가 가능하고 크레딧은 의무가 아니다.

- 페이지: https://0x72.itch.io/dungeontileset-ii
- 라이선스: Creative Commons Zero v1.0 Universal (CC0 1.0)
- 페이지 문구 (2026-11-07 확인):
  - "You can use this tileset for whatever you like (CC-0)."
  - "Credit is not necessary"
  - "Asset license: Creative Commons Zero v1.0 Universal"
- 파일: 소문자 이름 (`*_anim_f*.png`)
  - angel, big_demon, big_zombie, chort, doc, dwarf_f, dwarf_m, elf_f, elf_m, goblin, ice_zombie, imp, knight_f, knight_m, lizard_f, lizard_m, masked_orc, muddy, necromancer, ogre, orc_shaman, orc_warrior, pumpkin_dude, skelet, slug, swampy, tiny_slug, tiny_zombie, wizzard_f, wizzard_m, wogol, zombie

## 직접 만든 에셋

그 밖의 그림(보석, 석상, UI, 배경, 이펙트, 아이템)과 오디오(효과음, BGM)는 이 프로젝트에서 직접 만들었다. 외부 소스는 쓰지 않았다.
